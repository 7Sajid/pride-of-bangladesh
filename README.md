# 🇧🇩 Pride of BD — Bangladesh Academic & Science Talent Atlas

An interactive 3D WebGL and data exploration platform celebrating world-renowned Bangladeshi scholars, scientists, university professors, and educators who transformed the world through academic excellence and higher education.

Built with **Next.js 16 (App Router)**, **React Three Fiber (Three.js)**, **Tailwind CSS**, and **Framer Motion**, styled in the vibrant national colors of Bangladesh (Deep Emerald Green `#006a4e` & Crimson Sun Red `#f42a41`) with an authentic geographic silhouette of Bangladesh watermarked across crisp, modern ivory-white backdrops.

---

## 🌟 Key Highlights

- **Pure Focus on Academic & Intellectual Excellence**: Honors icons who achieved global stature strictly through universities, doctoral research, scientific discovery, and educational leadership (such as *Satyendra Nath Bose*, *Sir Jagadish Chandra Bose*, *Dr. Fazlur Rahman Khan*, *Dr. Jamal Nazrul Islam*, *Prof. Muhammad Yunus*, *Dr. M. Zahid Hasan*, *Sal Khan*, *Prof. Dr. Mohammad Kaykobad*, and more). No pop culture or sports celebrities.
- **Interactive 3D Constellation & Orbit Atlas**: Powered by Three.js / React Three Fiber, featuring interactive orbit rings representing research domains, connecting nodes, and real-time hover cards.
- **National Visual Identity**: White ambient theme infused with Bangladesh flag green (`#006a4e`) and flag sun-red (`#f42a41`), accompanied by an SVG geographic outline of Bangladesh and river deltas.
- **Hall of Fame & Directory**: Fast client-side fuzzy search, category filtering (Physics, Computing, Academia, Education & Impact, Industry Leadership, Architecture), and country badges.
- **Interactive Slide-Over & Detail Profiles**: Comprehensive biographies, doctoral & university credentials, international awards, institutional affiliations, and relation network links.
- **Community Nomination Portal**: Allows the community to nominate academic achievers with verification links.
- **Fully Responsive & Accessible**: Graceful tier fallback for devices without WebGL acceleration.

---

## 🚀 Tech Stack

- **Framework**: [Next.js 16 (Turbopack, App Router)](https://nextjs.org/)
- **Language**: TypeScript
- **3D Graphics**: Three.js, React Three Fiber (`@react-three/fiber`), Drei (`@react-three/drei`)
- **Styling**: Tailwind CSS v4 & custom CSS tokens
- **Animations**: Framer Motion
- **State Management**: Zustand
- **Icons**: Lucide Icons & SVG

## 📦 Getting Started

### Prerequisites
- Node.js 18.17+ (or Node 20+)
- npm or pnpm / yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/NafisUlAmanSaadman/PrifdeOfBd.git

# Enter project directory
cd PrifdeOfBd

# Install dependencies
npm install

# Start local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
